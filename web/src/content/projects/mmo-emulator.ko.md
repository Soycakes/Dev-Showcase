4명의 개발자와 협업하여, 동시 접속자 1,000명 이상을 수용할 수 있는 고성능 대용량 아키텍처 서버 시스템 개발을 도움.

반복적인 수동 데이터 변환/제작 작업을 개선하고자 엑셀 데이터를 규격에 맞게 XML, .dat, SQL 포맷으로 자동 변환하는 특수 파이프라인을 구축해, 디자이너 및 기획 생산 협업을 혁신.

ElasticSearch를 연동하여 실시간 게임 내 마켓, 거래 데이터 및 유저 플레이 통계 분석 시스템을 구축하고, 인게임 경제 및 데이터 기반의 밸런싱을 위한 통계 데이터 제공.

NavigableMap을 활용하여 수천 개의 데이터셋을 즉각적으로 처리하는 퀘스트 시스템을 개발.
