Co-developed an Android drawing application with a custom canvas supporting dynamic brush shapes, sizes, and colors.

Implemented high-performance canvas path rendering in Kotlin using Android's graphics Canvas APIs and custom coordinates calculation for multi-touch paths.

Integrated Android NDK/C++ via JNI to perform low-level bitmap manipulation for color inversion and brightness adjustment directly on locked pixel buffers.

Created a hybrid UI merging Jetpack Compose with XML ViewBinding to list local drawings queried from a Room database and cloud drawings downloaded from Firebase Storage.

Wrote Espresso and Compose instrumented tests verifying touch drawing paths, screen rotation survival, and native C++ image processing logic.
