리드 프로그래머 겸 컴뱃 디자이너로서 Agile/Waterfall 하이브리드 방법론을 기반으로 한 30명 이상의 대규모 팀 협업 완수.

C# Coroutine 및 Async/Await 로직 설계로 모듈형 보스 State Machine을 제작해, 5종 이상의 고유 보스와 50종 이상의 다양한 Enemy Pattern 로직을 제어했으며, 기획자들이 직접 값을 튜닝할 수 있도록 개발툴 및 문서를 구축.

Unity ScriptableObjects를 활용한 설계로 100여 가지의 공격 변형 및 투사체 데이터 구조를 관리하여 코드 재사용성을 극대화하고, "디자이너와 엔지니어 간"의 병목 현상을 제거하여 개발 주기를 50% 단축.

Perforce를 이용한 코드 승인 및 형상 관리 파이프라인을 운영하였으며, Branch Workflow를 확립하여 다수 프로그래머 간의 Code Conflict 최소화.
